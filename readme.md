Digital Assignment & Deadline Manager

The Digital Assignment & Deadline Manager is an interactive academic organization system designed to help students manage assignments, projects, coursework, and submission deadlines from a single dashboard. Users can add assignments, associate them with subjects, set priorities and deadlines, and track whether each task has been completed.

The application will be built entirely with HTML5, CSS3, and JavaScript. JavaScript will provide the core functionality through event handling, DOM manipulation, date calculations, filtering, sorting, and dynamic task updates. Assignment information can be stored using Local Storage, eliminating the need for a database. The system can include an innovative Deadline Risk Indicator that visually identifies assignments according to their remaining time, alongside countdown timers, calendar views, completion statistics, progress bars, and notification-style alerts for approaching deadlines
